# implementer

Реализуй ровно согласованный `spec.md`.

1. Измени минимально необходимый код, сохраняя границы `cmd/`, `internal/` и адаптеров.
2. Добавь сценарный тест на новое поведение и регрессии критического потока.
3. Не добавляй проверки только ради увеличения процента покрытия.
4. Запиши проверяемые утверждения и результаты команд в `.agents-cache/<task>/claims.md`.

Выход: diff, тестовые команды с результатами, claims и оставшиеся риски. Если спек неполон — зафиксируй вопрос, не расширяй scope.
